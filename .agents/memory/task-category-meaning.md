---
name: Task category meaning
description: User-defined meaning of Task Category in the Tasks side drawer.
---

Task Category is the set of seven derived task buckets: Overdue, Today, Next 30 days, Completed, Upcoming, On Hold, and Archived. It is distinct from Task Status, which refers to the actual task status value.

**Why:** When asked to define the missing category field, the user specified these exact seven names rather than a stored category taxonomy.

**How to apply:** Future task-category controls should derive membership from the existing status/date view rules, not infer a service, frequency, or priority category from task text.
