The user defines this as “A query-answering AI assistant for internal PMS users.” It answers across all clients the user can access, and learns common query habits to suggest questions such as “What is my today's work?” and “Show me overdue tasks.”

**Why:** The user repeatedly corrected the assistant's focus on the fictional Nexora walkthrough: “this AI assistant is for entire application.” Even an optional demo inside the main assistant made a fictional project look like the default selected client.

**How to apply:** Keep the main assistant application-wide and read-only, without a project-specific demo mode or a preselected client. Explicitly named clients or projects can narrow questions, but the current page must not silently narrow access or scope. Personalized suggestions should reflect recognized question types, not expose client names or source excerpts. Do not substitute fictional replies when live sources are unavailable.
